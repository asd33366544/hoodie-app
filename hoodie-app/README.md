# 🎓 Medical Sciences Hoodie Collection App

تطبيق لجمع مقاسات وبيانات الطلاب لهودي التخرج مع لوحة تحكم لتصدير البيانات إلى ملفات Excel مباشرة، مدعوم بقاعدة بيانات Supabase مجانية.

---

## 🔗 الروابط المباشرة (Live Links)

- 👕 **رابط استمارة الطلاب (Public Form):**  
  [https://hoodie-app-chi.vercel.app/](https://hoodie-app-chi.vercel.app/)

- 📊 **رابط لوحة التحكم والإدارة (Admin Dashboard & Excel Export):**  
  [https://hoodie-app-chi.vercel.app/admin](https://hoodie-app-chi.vercel.app/admin)

---

## 🚀 المميزات

- ✨ واجهة عصرية Glassmorphism مع خلفيات متغيرة عشوائياً.
- ⚡ اتصال مباشر وسريع وآمن مع قاعدة بيانات **Supabase (PostgreSQL)**.
- 📋 نموذج إدخال بسيط للطلاب لتسجيل الاسم، القسم، ومقاس الهودي.
- 📊 لوحة تحكم للآدمن لعرض الإحصائيات والإدخالات فورياً.
- 📥 تصدير البيانات إلى شيت **Excel (.xlsx)** بضغطة زر واحدة من المتصفح.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend:** React 19, Vite, Lucide Icons, Vanilla CSS
- **Database:** Supabase (PostgreSQL)
- **Export:** SheetJS / XLSX
- **Deployment:** Vercel
